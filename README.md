# Silver-Showrunner Alpha.7 Master

面向中文 AI 影视创作者的全流程总导演 Skill。当前版本：`v1.1.3`。

它可以把创意、小说、剧本、已有分镜或素材进度，继续推进为剧情拆解、角色与场景方向、导演分镜、逐镜视频提示词、连续性检查和制作记录。

## 最重要的能力

- 完整读取小说或剧本，从用户已有进度继续。
- 保留来源顺序、关键剧情和逐字对白，不为了缩短而静默删减。
- 把动作节拍和摄影镜头分开，写清动作因果、可见结果和相邻镜头交接。
- 为每个镜头生成可单独复制的视频提示词，包含表演、动作、摄影、声音、接触关系和结束画面。
- 检查对白时长、说话顺序、口型责任、跨镜声音和字幕覆盖。
- 支持长篇分批、恢复点、素材版本、制作进度和成本登记。
- 没有真实生成并观看媒体时，如实保持 `NOT_TESTED`，不把文字检查说成成片检查。

## 一分钟开始

1. 支持 Skill 或 ZIP 的工具：到 Releases 下载同名 `.skill` 或 ZIP，二选一。
2. 只支持一个 Markdown 的工具：到 Releases 下载适合任务的 `ONEFILE.md`。
3. 再上传小说、剧本、分镜或素材说明，然后发送：

> 请使用 Silver-Showrunner-alpha.7-Master v1.1.3，完整读取我提供的文件，从当前进度继续。先用普通中文说明你的理解，再完成剧情拆解、导演分镜和每镜可直接复制的视频提示词。保留原有对白，不要缩减关键剧情、动作、声音和镜头衔接。

之后可以直接说“继续”“修改第几镜”或“按我的意见重做这一段”。

## 选哪个文件 / 使用方式

| 使用环境 | 推荐文件 |
|---|---|
| 支持 Skill | `Silver-Showrunner-alpha.7-Master-v1.1.3.skill` |
| 支持 ZIP | `Silver-Showrunner-alpha.7-Master-v1.1.3.zip` |
| 小说、长篇改编 | `LONGFORM-ONEFILE.md` |
| AI 漫剧或短剧核心创作 | `MANGA_CORE-ONEFILE.md` |
| 只跑纯文字测试 | `TEXT_ONLY_ECO-ONEFILE.md` |
| 需要全部模型可读创作能力 | `FULL-ONEFILE.md` |

核心创作文件本身已经支持跨集连续性；`LONGFORM` 另外加入纯文字长篇测试与恢复工作流，更适合小说或整季项目。

不要在同一轮同时加载运行包和 ONEFILE，选择一种即可。

## 仓库里的 SKILL.md 是什么

仓库根目录的 `SKILL.md` 是真实的模块入口，带标准 frontmatter，并按需读取 `references/`、`engines/` 和 `phases/`。它不是把全部文件拼在一起的单文件版。

只能上传一个 Markdown 时，请从 Releases 下载 ONEFILE。这样 GitHub 安装入口和单文件使用不会互相破坏。

## v1.1.3 做了什么

- 把公开参考模块统一改为稳定的功能名称。
- 同步迁移路由、依赖、校验器、构建器、测试和所有单文件索引。
- ONEFILE 改为从功能种子计算依赖闭包，缺依赖或循环会停止构建。
- `FULL` 覆盖全部模型可读运行模块，同时排除只供工具或审计使用的资料。
- 新增公开修订名和禁用内容硬门禁，路径、正文、归档成员与 ONEFILE 一起检查。
- 保留旧项目的受控迁移能力，但不再把历史代号暴露成公开运行文件名。

## 验证边界

本版已通过本地源树、路由、状态、提示词、长篇、媒体流程、打包、解压和运行冒烟检查；ZIP 与 `.skill` 逐字节一致。禁用内容门禁的 97 组变异检查全部拦截，并且错误信息不会复述命中文字。

本次没有调用外部模型实际生成并观看图片、声音或视频，因此真实成片效果仍需在实际生成后确认。
