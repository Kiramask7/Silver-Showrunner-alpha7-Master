# Silver-Showrunner Alpha.7 Master

> 面向中文人工智能影视创作者的全流程总导演 Skill。

当前版本：`v1.1.2`

Silver Showrunner 可以把创意、小说、剧本、已有分镜或素材进度，继续推进为剧情拆解、角色与场景方向、导演分镜、逐镜视频提示词、连续性检查和制作记录。

它尤其重视剧本、对白、动作因果和镜头衔接。可复制的视频提示词不会为了缩短而删除关键剧情，也不会把多个镜头混成一条模糊指令。

## 主要能力

- 完整读取小说或剧本，从用户已有进度继续。
- 区分原始资料和新增导演方案，避免擅自改写剧情。
- 拆解剧情、场景、角色关系、动作和声音责任。
- 输出导演分镜与每镜可单独复制的视频提示词。
- 保留逐字对白，并检查对白时长、口型、动作和身体状态是否冲突。
- 登记相邻镜头之间的动作、位置、视线、道具、光线和声音交接。
- 支持长篇分批制作、恢复点和素材版本记录。
- 在没有真实素材时如实说明验证边界，不把文字检查说成成片检查。

## 应该使用哪个文件

| 文件 | 适合谁 |
|---|---|
| `Silver-Showrunner-alpha.7-Master-v1.1.2.skill` | 支持 Skill 文件的人工智能工具，优先选择。 |
| `Silver-Showrunner-alpha.7-Master-v1.1.2.zip` | 支持 ZIP 导入的工具；内容与 `.skill` 完全相同。 |
| `SKILL.md` | 不支持 ZIP、只能读取 Markdown 的人工智能；这是全能力单文件版。 |
| `1分钟说明使用手册.md` | 第一次使用时快速了解用途和操作。 |
| `银幕总控_Alpha.7_使用与指南.docx` | 更完整的图文使用指南。 |
| `银幕总控 Alpha.7 项目说明.ppt` | 项目介绍演示文稿，放在 GitHub 版本下载区。 |

不要同时向同一个人工智能提供 `.skill`、ZIP 和 `SKILL.md`。根据平台支持情况选择其中一种即可。

## 一分钟开始使用

1. 选择 `.skill`、ZIP 或 `SKILL.md` 中的一种交给人工智能。
2. 再上传你的小说、剧本、分镜或素材说明。
3. 复制下面这段话发送：

> 请使用 Silver-Showrunner-alpha.7-Master v1.1.2，完整读取我提供的文件，从我目前的进度继续。先用普通中文说明你的理解，再完成剧情拆解、导演分镜和每镜可直接复制的视频提示词。保留原有对白，不要缩减关键剧情、动作、声音和镜头衔接。

之后可以直接说“继续”“修改第几镜”或“按我的意见重做这一段”。

## 单文件版与完整运行包的区别

`SKILL.md` 保存了人工智能可以阅读的完整创作规则，适合 DeepSeek 等不支持 ZIP 的平台，能够完成核心的剧本、分镜和提示词工作。

`.skill` 和 ZIP 还包含本地辅助程序、结构检查器和运行文件。因此单文件版最接近完整创作能力，但不能在普通对话平台里自动执行这些本地程序。

## 使用提醒

- 有附件时先让人工智能完整读取，不要只贴零散片段。
- 需要逐字保留原话时，明确说明“对白逐字保留”。
- 每次只加载一种 Skill 形式，避免重复规则占用上下文。
- 大型长篇项目建议分阶段确认，并从最近的恢复点继续。
