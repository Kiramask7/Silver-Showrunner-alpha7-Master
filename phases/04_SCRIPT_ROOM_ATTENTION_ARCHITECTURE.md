# Stage 3 — 剧本室与注意力结构

剧本版本、决定授权与完成范围遵守 `../references/ALPHA7_RUNTIME_INTEGRITY_CONTRACT.md`。

剧本工作稿和注意力结构说明遵守 `creative_artifact_language`，角色实际对白遵守 `dialogue_language`。面向中文用户的审稿意见、风险和状态解释必须使用自然简体中文。

## 剧本室

按以下循环逐步工作：

`节拍 → 场景 → 对白与动作 → 复核 → 修订`

原创、改编和锁定范围修订均先读取 `../references/ALPHA7_CONTINUUM_CREATIVE_FIDELITY_ENGINE.md`。把当前范围的事件、对白、旁白、人物非词汇发声和必须可见的事实建立为有顺序的来源单元；默认全量交付，不靠聊天记忆或摘要判断覆盖。原创剧本形成可审阅版本后，该版本立即成为分镜与 Prompt 的下游来源真值；后续改变对白或事件必须建立新版本。

每个场景都必须回答：

- 为什么必须存在；
- 进入场景和离开场景时，人物、信息与局势分别是什么状态；
- 新增了什么信息；
- 冲突、选择或代价在哪里；
- 情绪发生了什么变化；
- 删除本场后，故事会损失什么。

每场还要明确可见入口、人物当下目的、阻力如何出现、逐步动作/反应、逐轮发声、可见出口及下一场继承。对白按说话人、逐字文本和来源种类记录；旁白、屏幕文字、环境声与人物非词汇发声不得互相冒充。用户要求不缩减时，来源单元必须完整覆盖，不能把冲突过程、人物反应或多轮对白压成场景摘要。

## 注意力结构

结合 Viral Genome 与当前平台、形式证据设计注意力，不使用脱离证据的万能时长教条。

映射：

- 让观众停下来的理由；
- 作品向观众作出的承诺；
- 升级节拍；
- 兑现时机；
- 继续观看的理由；
- 空转和死气风险；
- 解释密度；
- 反应与理解空间。

当前平台证据可以调整节奏，但不得在没有批准时改写核心故事。

中文稿完成一轮后，按 `../references/ALPHA7_CHINESE_COPY_AND_FOURFOLD_PREFLIGHT.md` 做自然表达回读：先冻结数字、日期、引文、专名、因果和核心主张，再减少模板化排比、空泛形容、机械小标题和“正确但不像人说”的句子。去除 AI 味不能改写事实或让真实角色说出不符合身份的话。

注意力结构只评估“是否让目标受众愿意继续理解、承诺是否兑现”。禁止把夸张标题、夸大结果、虚假稀缺或无来源数字当传播优化；不得输出爆款概率。

## 剧情文案按需加载

当任务真正包含剧情场景、人物对白或剧情旁白时，读取 `../references/SCRIPT_AND_DIALOGUE_WRITING_ENGINE.md`。它用于把械概落成可演的动作、关系变化和必要现场细节，但不允许改写来源事实、已锁定台词或剧情因果。

无对白动作、纯视觉段落、纪录片、科普、教程和专业材料不强制潜台词、情绪优先或剧情化感官细节。回读时根据语境判断重复、套话和抽象结论，不以单个词语命中作为自动退回理由。

第一个完整样场、发生过对白/顺序/删减修改的场景，以及最终范围的代表样场，准备 `SCRIPT` 模式预检 JSON，并只通过包根目录的 `运行银幕总控.cmd 创作预检 <创作预检.json> --output <机器报告.json>` 做本地保真检查。工具报告进入机器附件；普通用户只看到具体漏项或最低成本修复。预检通过不替代编辑审稿。
